# 💿 Инструкция по сборке Remix Hi-Fi Music Player

В проекте уже всё полностью подготовлено и настроено для сборки приложения под **Windows (.exe)** и **Android (.apk)**.

---

## Вариант 1. Сборка для Windows (.exe)

Создаёт полноценную программу для Windows:
- **Установщик (.exe / Setup)** с созданием ярлыка на рабочем столе и в меню Пуск.
- **Портативную версию (.exe / Portable)**, которая запускается сразу без установки.
- **Пропорциональное масштабирование:** окно сохраняет пропорции экрана смартфона / Hi-Fi плеера (430 × 880) при любом растягивании мышью в обе стороны.

### Быстрый запуск (1 клик):
Дважды нажмите на файл:
```text
build-windows-exe.bat
```

### Либо через командную строку (cmd / PowerShell):
```bash
# 1. Установить зависимости (если еще не установлены)
npm install

# 2. Собрать .exe файлы для Windows
npm run build:win
```

*Готовые файлы появятся в папке `release/`:*
- `release/Remix Player Setup 1.0.0.exe`
- `release/Remix Player 1.0.0.exe`

---

## Вариант 2. Сборка APK для Android / Эмуляторов Windows (WSA, BlueStacks, LDPlayer)

В проект уже добавлена платформа Android (`@capacitor/android`) со всеми необходимыми манифестами и плагинами.

### Требования для сборки APK:
- Установленная **Java JDK 17+** (переменная окружения `JAVA_HOME`).
- Либо установленный **Android Studio**.

### Быстрый запуск (1 клик):
Дважды нажмите на файл:
```text
build-android-apk.bat
```

### Либо через командную строку:
```bash
# 1. Установить зависимости
npm install

# 2. Собрать APK
npm run build:apk
```

*Готовый APK-файл появится в папке:*
```text
android/app/build/outputs/apk/debug/app-debug.apk
```

### Как открыть проект в Android Studio (если хотите подписать release-ключом):
```bash
npx cap open android
```
И в меню Android Studio выберите: **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.

## Особенности пропорционального растягивания на ПК

1. **В приложении для Windows (Electron):**
   При перетаскивании границ окна за любой угол или край окно принудительно изменяет ширину и высоту синхронно, сохраняя исходные пропорции Hi-Fi плеера.
2. **В веб-версии / браузере на мониторе:**
   Плеер центрируется на глубоком графитовом фоне с мягким контурным неоновым свечением, а пропорции контейнера плеера строго зафиксированы в соотношении `430 / 880`, автоматически подстраиваясь под размер экрана монитора без растягивания или сплющивания интерфейса.
